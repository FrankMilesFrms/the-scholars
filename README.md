# 《儒林外史 集校集注集评——附资料汇编》总序

## 本书的诞生

当代《儒林外史》专著多矣，如《儒林外史汇校汇评（增订本）》、《陈批儒林外史》等；而我想集大成也亦久矣，一来可以免去来回翻阅之苦，二来也能让读者更快、更广地理解《儒林外史》的语言艺术，不至于像我一样反复去读不同本子。这能节省读者大量的时间。所以尽可能汇集当代优秀的《儒林外史》评论、注释、题解和资料，成就了本书——《儒林外史 集校集注集评——附资料汇编》

由于版权法的保护，想要在保护期内汇集成一本，这种工作只能由“法外狂徒”去做了。因此，我必须在此明确地说明：这部书不以任何方式盈利，任何借助本文本收取费用的行为均是违法行为。

## 关于本书文本

底本采用李汉秋著的《儒林外史汇校汇评》、《儒林外史汇校汇评（增订版）》（简称“汇本”），注释和少部分分段标准参考了陈美林写的《陈批儒林外史》（含2014和2022版，简称“陈批”），注释也参考了张慧剑注释本（简称“张注”），题解部分采用的是陈美林先生写的《儒林外史人物论》（简称“陈解”），在此一并谢过。本书酌情修改了部分标点符号。

关于汉字繁简混杂情况：为了尽可能保留原始文本，这里一律混合使用。如果使用机翻统一为简体或繁体，容易导致翻译错误，反而得不偿失。凡重叠的文本处，均采用繁体版本。
